# DOON 조사·분석 자료

공모전 기간(2026-10-13 ~ 10-30)에 진행한 조사, 측정, 설계 검토, 실험 기록을 모은 폴더다.
수치는 각 문서를 쓴 시점 기준이며, 매크로 방어의 최종 구조와 결과는 [13-macro-defense.md](13-macro-defense.md)에 있다.

## 프로젝트 목적 (모든 판단의 기준)

> 대규모 선착순 서비스에서 발생하는 **지리적 불공정성**을, KOREN 전국 PoP 구조를 이용해
> **① 엣지 스탬핑**과 **② 매크로 방지**로 줄인다.

발표용 한 문장(제안):

> 대규모 선착순에서 승부는 '누가 먼저 눌렀나'가 아니라 '**어디서, 무엇으로** 눌렀나'로 갈린다.
> DOON은 KOREN 전국 PoP로 **엣지 스탬핑으로 거리의 차이를, 매크로 방지로 도구의 차이를** 없애
> 먼저 누른 사람이 이기게 한다.

## 핵심 결론 요약

1. **지리적 격차는 업계·정부 모두 다루지 않는 빈칸이다.** 업계와 제도는 매크로에만 집중하고, 대기열도 "서버 도착순"이다. DOON이 들어갈 자리가 분명하다.
2. **엣지 스탬핑의 원리는 금융 거래소 연구(CloudEx, HotOS 2021)에 선례가 있다.** 숨기지 말고 "검증된 원리를 국가 연구망 위 일반 시민 서비스로 처음 옮겼고, 매크로 방지를 같은 판정 구조에 결합했다"로 위치를 잡는다.
3. **지역 격차 실측(2026-10-14):** 같은 KT 가정용 회선이라도 전남(목포·나주)은 수도권(수원·평택)보다 서울 서버까지 왕복 1.3~3.5ms 더 걸린다. 판교·대전 서버에서 실제 예매 사이트 5곳에 직접 접속해 봐도 대전이 모두 약 2ms 더 걸렸다. 시계가 보장하는 한계(판교 약 1.4ms, 대전 약 2.4ms) 안의 차이는 순서를 주장하지 않고 검증 가능한 추첨으로 정한다. 같은 순간 대결(2026-10-16)에서 기존 방식은 대전 0/99, DOON은 54/99였다. [11-duel.md](11-duel.md) [06-regional-gap.md](06-regional-gap.md)
4. **용량:** central 판정은 모드와 무관하게 초당 약 1.6만 건. Redis 2단계(DB 배치)는 대량 동시 확정에서 가장 빠르고 유실이 없다. 실제 병목은 PoP(초당 약 2,140건)이며, 지금 구성은 PoP당 동시 접속 약 800~1,000명이다.
5. **AI 매크로 설계는 방향이 좋지만** 설계서의 "구현됨/진행" 표기와 실제 코드 차이가 크고, 남은 기간에 맞게 범위를 줄여야 한다. 검증은 나중에 하더라도 사전 등록·라벨 분리·레드팀 분리는 지금 설계에 넣어야 한다.
6. **AI 매크로 실험 (2026-10-15):** 격리 실험판에서 서울 AI가 "5회 도착 시각의 표준편차가 약 12.6ms 이하면 의심"을 기록에서 찾고 실험판 PoP에 0.2초 만에 자동 전파했다. 처음 보는 매크로는 5번째 관찰 뒤 차단, 사람은 360건 중 0건 차단(대전·판교 동일). 지연을 50ms 이상 섞는 고급 봇은 시간만으로는 못 잡는다는 한계도 확인했다. [09-ai-macro-results.md](09-ai-macro-results.md)

## 표기 원칙

- 출처는 각 문서 끝에 링크로 남겼다. 블로그·업체 자료·기자수첩처럼 근거가 약한 것은 본문에 그렇게 표시했다.
- 프리프린트(동료심사 전)와 동료심사 논문을 구분했다. 발표 인용 전 원문을 다시 확인한다.
- 평가·발표 논의에서는 판교 PoP도 외부에서 접속 가능하다고 가정한다.
